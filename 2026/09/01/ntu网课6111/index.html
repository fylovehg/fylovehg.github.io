EE6111 Week1 Exam‑Ready Summary

一、Course Basic Info 课程基础信息

  1. 5G三大应用场景
  • 增强移动宽带
      Enhanced Mobile Broadband, eMBB：High data rate, for AR/VR, 4K/8K video, cloud service
  • 海量机器类通信
      Massive Machine‑Type Communications, mMTC：Massive low‑power IoT devices; smart home, environment monitoring, smart agriculture
  • 超高可靠低时延通信
      Ultra‑Reliable Low‑Latency Communications, URLLC：Ultra‑low latency & high reliability; autonomous driving, industrial automation, e‑health
  1. OSI七层模型
  • 应用层 Application Layer
  • 表示层 Presentation Layer
  • 会话层 Session Layer
  • 传输层 Transport Layer
  • 网络层 Network Layer
  • 数据链路层 Data Link Layer
  • 物理层 Physical Layer
  1. 免许可ISM频段
      ISM bands (Industrial‑Scientific‑Medical bands)：Unlicensed frequency spectrum, e.g. 902‑928 MHz, 2.4 GHz, 5.8 GHz

二、Wireless Communication Fundamentals 无线通信基础

  1. 电磁波基本关系
    $$c=f\lambda$$
  • $c$：光速 speed of light
  • $f$：频率 frequency
  • $\lambda$：波长 wavelength
  1. 无线通信两大难点
  • 衰落 Fading：Time‑variation of received signal strength
    • 大尺度衰落 Large‑scale fading：Caused by path loss & shadowing over large distance (cell‑size scale)
    • 小尺度衰落 Small‑scale fading：Multipath interference, varies over carrier‑wavelength scale
  • 干扰 Interference：Unwanted signal from other transmitters degrades reception
  1. 天线 Antenna
  • 天线有效面积
    $$A_e=\frac{\lambda^2 G}{4\pi}$$
      $A_e$ effective aperture / effective area；$G$ antenna gain 天线增益
  • 等效全向辐射功率
    $$\text{EIRP(dBm)}=P_T(\text{dBm})+G_T(\text{dBi})-L_{\text{cable}}$$
      EIRP (Effective Isotropic Radiated Power)：Total radiated power referenced to isotropic antenna
      $P_T$ transmit power发射功率；$L_\text{cable}$ cable loss线缆损耗

三、Large‑Scale Propagation Models 大尺度传播模型（Path loss）

1. Free‑space path loss 自由空间模型

$$\frac{P_R}{P_T}=G_T G_R\left(\frac{\lambda}{4\pi d}\right)^2=G_T G_R\left(\frac{c}{4\pi f d}\right)^2$$

  • $P_T$ transmit power发射功率
  • $P_R$ received power接收功率
  • $G_T$ transmit antenna gain发射天线增益
  • $G_R$ receive antenna gain接收天线增益
  • $d$ transmitter‑receiver separation distance收发间距

自由空间路径损耗（dB）
$$L_F(\text{dB})=10\log_{10}\frac{P_T}{P_R}=-10\log_{10}G_T-10\log_{10}G_R+20\log_{10}f+20\log_{10}d+k$$
$$k=20\log_{10}\left(\frac{4\pi}{3\times10^8}\right)=-147.56$$
  $L_F$ free‑space path loss；Rule: doubling distance → +6 dB loss

2. General path‑loss power‑law model 通用路径损耗幂律模型

$$L(d)[\text{dB}]=L(d_0)+10n\log_{10}\left(\frac{d}{d_0}\right)$$

  • $L(d_0)$：参考距离处路径损耗 path loss at reference distance $d_0$
  • $d_0$：参考距离 reference distance
  • $n$：路径损耗指数 path‑loss exponent：Free‑space $n=2$

3. Empirical propagation models 经验工程模型

  1. Okumura model
    $$L_{50}(\text{dB})=L_F+\hat{A}{mu}+\hat{H}{tu}+\hat{H}{ru}$$
      Okumura model: Empirical median path‑loss for urban area; $L    {50}$ = median (50‑percentile) path loss 中位数路径损耗

  2. Hata model (urban)
    $$
    \begin{aligned}
    L_{50}(\text{dB}) =& 69.55+26.16\log f_c-13.82\log h_t-a(h_r) \
    &+(44.9-6.55\log h_t)\log d
    \end{aligned}
    $$
      Hata model: Simplified formula derived from Okumura measurements
      $f_c$ carrier frequency载波频率；$h_t$ base‑station antenna height基站天线高度；$h_r$ mobile antenna height移动台天线高度；$a(h_r)$ mobile‑antenna height correction factor移动天线高度修正因子

  Suburban correction 郊区修正、Open‑area correction 开阔地修正

  1. COST231‑Hata extended model
    $$
    \begin{aligned}
    L_{50}(\text{dB}) =& 46.3+33.9\log f_c-13.82\log h_t-a(h_r) \
    &+(44.9-6.55\log h_t)\log d+C
    \end{aligned}
    $$
      COST231‑Hata: Extend Hata to 1500‑2000 MHz; $C$ constant, $C=3\ \text{dB}$ for metropolitan centres

4. Log‑normal shadowing 对数正态阴影模型

$$L(d)[\text{dB}]=\overline{L(d)}+X_\sigma$$

  • $\overline{L(d)}$：平均路径损耗 mean path loss
  • $X_\sigma$：零均值高斯随机变量 zero‑mean Gaussian random variable (dB)；$\sigma$ shadowing standard deviation阴影标准差

Log‑normal shadowing: Random attenuation caused by obstacles; path loss in dB follows Gaussian distribution.

5. Vegetation loss models 植被衰减

ITU model:
$$L(\text{dB})=0.2F^{0.3}d_f^{0.6}$$
COST235 model:
$$L(\text{dB})=26.6F^{-0.2}d_f^{0.5}\quad(\text{out of leaf})$$
$$L(\text{dB})=15.6F^{-0.009}d_f^{0.26}\quad(\text{in leaf})$$
$F$ frequency(MHz); $d_f$ depth inside vegetation (metres)

四、Small‑Scale Multipath Fading 小尺度多径衰落

1. Envelope distribution 包络统计

  1. Rayleigh fading 瑞利衰落（No line‑of‑sight (No‑LOS)，无直射视距）
    Probability density function PDF：
    $$p_r(r)=\frac{r}{\sigma^2}\exp\left(-\frac{r^2}{2\sigma^2}\right),\ r\ge0$$
    Cumulative distribution function CDF：
    $$P(r\le R)=1-\exp\left(-\frac{R^2}{2\sigma^2}\right)$$
    Mean value：
    $$E[r]=\sigma\sqrt{\frac{\pi}{2}}$$
    Phase distribution：
    $$p_\theta(\theta)=\frac{1}{2\pi}$$
      **PDF (Probability Density Function)**概率密度函数
      **CDF (Cumulative Distribution Function)**累积分布函数
      $\sigma^2$ mean received power平均接收功率；Phase is uniformly distributed over $(0,2\pi)$相位均匀分布

  2. Rician fading 莱斯衰落（With line‑of‑sight (LOS) dominant component存在视距直射分量）
    $$p_r(r)=\frac{r}{\sigma^2}\exp\left(-\frac{r^2+r_s^2}{2\sigma^2}\right)I_0\left(\frac{r r_s}{\sigma^2}\right)$$
      $I_0(\cdot)$: zero‑order modified Bessel function零阶第一类修正贝塞尔函数
    Rician K‑factor：
    $$K(\text{dB})=10\log_{10}\frac{r_s^2}{2\sigma^2}$$
      K‑factor: Ratio of power of LOS component to power of random multipath components. $K=0$ → reduces to Rayleigh fading.

2. Doppler effect / Doppler shift 多普勒效应 / 多普勒频移

$$f_d=\frac{v}{\lambda}\cos\alpha$$

  • $f_d$ Doppler shift多普勒频移
  • $v$ mobile velocity移动台速度
  • $\alpha$：入射波与移动方向夹角 angle between incoming wave and mobile moving direction

Physical meaning: Relative motion between Tx and Rx causes frequency shift of received signal.

3. Two classification dimensions for small‑scale fading

(1) Based on Doppler spread (time‑selective fading) 基于多普勒扩展（时间选择性衰落）

  • 多普勒扩展 Doppler spread $D_s$：Spectral broadening caused by mobile motion
  • 相干时间 Coherence time $T_c$：$T_c \approx \dfrac{1}{D_s}$；Time duration over which channel impulse response is approximately constant
    • 慢衰落 Slow fading: $T_c >$ symbol period; channel roughly constant over one symbol
    • 快衰落 Fast fading: $T_c <$ symbol period; channel changes within one symbol

(2) Based on delay spread (frequency‑selective fading) 基于时延扩展（频率选择性衰落）

  • 时延扩展 Delay spread: Time difference between earliest and latest multipath components
  • 相干带宽 Coherence bandwidth: Frequency range over which channel frequency response is flat
    • 平坦衰落 Flat fading: Delay spread < symbol period; all frequency components fade equally; no ISI
    • 频率选择性衰落 Frequency‑selective fading: Delay spread > symbol period; different frequencies experience different fading; causes **ISI (Inter‑Symbol Interference)**码间干扰

4. Level Crossing Rate & Average Fade Duration（Rayleigh channel）瑞利信道

  • 电平交叉率 LCR
    $$N_R=\sqrt{2\pi}f_m \rho e^{-\rho^2}$$
      Level Crossing Rate(LCR): Expected number of positive‑going crossings across threshold level per second
  • 平均衰落时长
    $$\overline{\tau}=\frac{e^{\rho^2}-1}{\sqrt{2\pi}f_m \rho}$$
      Average fade duration: Average time the signal envelope stays below threshold level
  • $f_m$ maximum Doppler frequency最大多普勒频率
  • $\rho = R/R_{\text{rms}}$：归一化电平 normalised threshold level
