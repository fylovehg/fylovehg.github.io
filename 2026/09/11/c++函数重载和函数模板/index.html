c++重载和函数模板

FY暂无分类2026-9-11

C++ 重点知识点总结（函数重载、函数模板、auto、decltype、模板参数）

素材来源于课程字幕文档，把核心概念、规则、坑点 + 可运行示例整理出来。

一、函数重载（Overload）

仅 C++ 支持，C 语言原生不支持函数重载

1. 概念

同一个作用域，函数名相同，参数列表不同，编译器根据实参的个数、类型、顺序自动挑选对应的函数。
目的：功能相近的函数复用同一个函数名，调用方便。

2. ✅构成重载的条件（核心：参数列表不一样）

区分依据只看形参列表：参数的个数、类型、参数顺序。
返回值不能作为重载区分依据！！

示例：求平均数

3. ❌不能构成重载的典型坑点

坑 1：仅返回值不一样，参数完全一样，不能重载

原因：调用函数可以不接收返回值，编译器没有办法判断你想要哪一个版本。

坑 2：数组形参和指针形参等价，不能重载

int arr[] 编译器处理为 int* arr，二者是同一个类型。

坑 3：值传递参数加const不能构成重载

值传递：int a 和 const int a，不能重载

const 只修饰函数内部的局部副本，外部调用看不出差别。

坑 4：普通引用 vs const 引用：可以构成重载

变量可以传给普通引用；字面量 / 临时对象只能绑定 const 左值引用，编译器可以区分，所以可以重载。

坑 5：重载 + 默认参数，引发二义性

4. 底层原理：名字改编 (name mangling)

C++ 编译器把重载函数名根据参数列表改成不同的底层符号；C 语言没有这个机制，所以 C 不能重载。

二、函数模板 function template

1. 概念

模板不是可执行代码，是代码生成图纸。编译器根据调用时传入的类型，自动实例化生成对应类型的函数实体。

语法：

示例：求三个数平均值

两种使用方式：

  1. 自动推导：ave(1.0,2.0,3.0)，编译器看实参类型反推 T
  2. 显式指定模板参数：ave<int>(1,2,3)，尖括号手动指定类型

2. 多模板参数（T1,T2）

可以有多个类型参数，用逗号隔开。

3. 模板特化（特例处理）

通用模板对某些类型逻辑不对，可以写特化版本，优先匹配特化；没有特化就用通用模板生成。

例如模板处理指针，本意想要比较指针指向的值，但是模板默认直接比较地址，结果错误，就需要特化处理指针版本。

4. 函数模板 + 函数重载优先级

调用时优先级：

  1. 普通重载函数（最高优先级，优先使用）
  2. 模板特化版本
  3. 通用函数模板，实例化出新函数

如果写了普通重载，编译器优先调用普通函数，不去实例化模板。

5. 非类型模板参数（模板参数不一定是类型，可以是常量值）

不是类型，编译期常量，实例化的时候替换为常量，运行期不能修改。

⚠️注意：MAX = 2000; 这种写法非法，MAX 是编译期常量，不是运行变量。

6. 模板的代价

模板是编译期生成代码，每一组不同模板参数，编译器生成一份独立函数，会带来代码膨胀，多个实例，不同内存地址。

模板本身没有机器码；只有被使用，才实例化生成机器码。

三、auto 类型推导

核心规则

  1. auto 从初始化表达式推导类型；auto 会丢弃引用、const 属性。
  1. auto 必须初始化，没有初始化无法推导。

auto 不能保留引用 /const，所以引出decltype

四、decltype(表达式)

decltype：不执行表达式，只分析表达式得到类型，可以保留 const、引用属性。

规则

  1. 如果表达式是变量名（没有运算）：decltype 完整保留变量的const、&引用属性。
  1. 如果表达式经过运算（算术运算、解引用*p）
    • 如果表达式结果是左值（拥有内存实体） → decltype 得到引用类型
    • 如果表达式是临时右值，没有持久内存 → 值类型，不带引用

重点：decltype不会运行括号内代码，仅仅静态分析语法得到类型。

拖尾返回类型（C++11）

当返回类型依赖参数运算结果，无法提前写死返回值：

-> decltype(a+b)拖尾返回，告诉编译器返回类型是a+b的类型。
C++14 之后支持 auto 直接推导返回值，可以省略拖尾。

六、关键考点速记（背诵版）

  1. ✅函数重载：只看参数列表（个数、类型、顺序）；返回值无效；C 语言不支持。
  2. ✅int a 和const int a值传递，不能重载；int&与const int&引用可以重载。
  3. ✅数组形参int arr[]等价int* arr，不能重载。
  4. ✅函数模板是图纸，编译期实例化生成函数；不使用就不会生成代码。
  5. ✅模板参数分两种：类型参数typename T；非类型模板参数是编译期常量，运行不能修改。
  6. ✅auto会剥除const和引用；decltype(expr)保留 const、引用，不执行表达式。
  7. ✅调用优先级：普通重载函数 > 模板特化 > 通用模板实例化。
  8. ✅模板会产生多份实例，注意代码膨胀问题。
  9. ✅临时对象（字面量）只能绑定const T&，不能绑定普通非常量左值引用。
