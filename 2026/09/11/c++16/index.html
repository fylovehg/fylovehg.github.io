C++ 17函数进阶 核心知识点（结合课程字幕内容）举例说明

素材来源：课程讲解：右值引用、函数底层本质、栈运行原理、寄存器、函数调用栈帧、栈溢出原理，全部配极简可运行示例。

1. 左值、右值、右值引用 && 移动语义（课程重点）

概念

  • 左值 (lvalue)：有持久内存、能取地址，可以被修改的对象；变量名、普通变量都是左值。
  • 右值 (rvalue)：临时对象，用完马上销毁，没有持久身份，临时返回值、字面量都是右值。
  • 右值引用 T&&：专门绑定右值（临时对象），符号是两个&&，不是引用的引用！

课程原话：右值引用就是 “废物利用”，直接接管临时对象内存，不重新分配内存，避免拷贝开销。

示例

✅关键点：

  1. && = 右值引用，不是 “引用的引用”；&是左值引用
  2. 右值引用只能接临时对象（右值）；可以延长临时对象生命周期
  3. 目的：避免临时对象拷贝，零额外内存分配，移动语义的基础

2. 函数的本质（课程汇编底层重点）

课程核心：

  1. 函数名本质就是一块内存地址；函数体 = 编译后的机器二进制指令。
  2. exe 保存在硬盘；运行时，操作系统把 exe 加载进内存。
  3. 函数调用：call指令跳转到函数地址；ret指令执行完跳转回去。
  4. 函数返回值，32 位下通过寄存器 EAX 传递，不是栈。

3. 栈 (stack)、栈帧、寄存器 ESP/EBP（重中之重）

课程核心知识点总结：

  1. 栈是操作系统程序启动就预先分配好的连续内存（默认大小 1MB 左右），用来存放局部变量、函数参数、返回地址。
  2. ESP：栈顶寄存器，标记栈当前使用位置；push ESP-4；pop ESP+4。
  3. EBP：栈基址寄存器，栈帧的基地址，访问局部变量、函数参数靠 EBP 做偏移：EBP+8取第一个参数，EBP‑4取局部变量。
  4. 每次函数调用形成一个栈帧；sub esp, N 在栈上开辟 N 字节给局部变量；
  5. 栈平衡：调用函数 push 多少参数，调用结束就要恢复 ESP，否则程序跑飞。
  6. 返回地址存在栈上！！！栈溢出攻击原理：覆盖栈上保存的返回地址，修改程序执行流。

5. 函数指针（下节课预告知识点）

课程：函数名是内存地址，可以存到函数指针。

核心问题：为什么 fp(1,2) 就能直接跑函数？

先确认：
fp 是函数指针变量，它里面存的值，是 add 函数的内存入口地址。

  1. 底层机器视角（CPU 层面）
  • add 函数编译后，会变成一堆 CPU 指令，存放在代码段内存，从地址比如 0x401560 开始。
  • fp 这个变量，在栈上，它存的就是这个数字：0x401560。

当 CPU 执行 fp(1, 2)：

  1. 把实参 1、2 压栈（函数传参）
  2. 取出 fp 里面保存的地址 0x401560
  3. CPU 跳转到这个内存地址去执行指令（call 跳转）
  4. 跑 add 的汇编代码，做加法，返回结果

本质：fp(1,2) 告诉编译器：不要把 fp 当成普通变量，把 fp 存的那个地址当作函数入口，跳过去执行。

  1. C++ 语法层面：函数调用运算符 ()

() 叫函数调用运算符。
语法规则：

如果 () 左边不是函数名，而是一个函数指针，编译器就会：
读取指针里面保存的函数入口地址，跳转到该地址执行函数。

两种写法100% 等价：

👉 (*fp)：对函数指针做解引用，得到那个函数本身；然后加()调用。
但是 C++ 做了语法糖：调用的时候可以把 * 省略掉，直接写 fp(1,2)。

课程重点记忆清单

  1. ✅ T&& 右值引用，绑定临时右值，复用临时对象内存，减少拷贝；不等于引用的引用。
  2. ✅ 函数本质：内存上一段二进制机器码；函数名 = 内存地址；返回值 EAX 寄存器传递。
  3. ✅ 栈：预先分配内存，存放局部变量、参数、返回地址；ESP 栈顶，EBP 栈基址。
  4. ✅ 栈溢出根源：栈上数组越界写，篡改栈保存的返回地址，劫持 EIP 指令寄存器。
  5. ✅ int* &&（右值引用） vs int* &（指针的左值引用），语法不要混淆。
